# Airline Customer Satisfaction Prediction

Satisfaction isn't in the data. It has to be constructed from it — and that distinction matters.

A collaborative ML project exploring patterns behind airline customer satisfaction.

Worked through preprocessing, feature engineering and model building, then used visual analysis to communicate findings beyond the code.
